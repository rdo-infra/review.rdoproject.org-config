# rdoproject-config

Zuul CI configuration for the RDO project.

The Zuul tenant configuration has moved to:

https://gitlab.com/softwarefactory-project/config

The Zuul instance has been migrated from softwarefactory-project.io to a new
deployment managed by the sf-operator at:

https://gateway-cloud-softwarefactory.apps.ocp.cloud.ci.centos.org/zuul/

## Review Process

To request a review and approval, please ping a member of the `config-ptl` or `config-core` group on the review.
This will ensure that your review is not abandoned and will be attended to in a timely manner.

Do not forget to include at least one of these group members in the `Reviewers` field of your `Review` change.

Only the members of these groups can add a `Workflow +1`, to run the `gate` pipeline.
